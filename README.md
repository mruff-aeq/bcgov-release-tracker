No install. No clone. No setup. Click link. See releases. Done.

---

## What this?

Cave team ship code for BC Registries. Cave team need know two things:

1. **What waiting to go to TEST?**
2. **What already in TEST?**

This page answer both. Page watch bcgov repos (`lear`, `business-filings-ui`, `business-create-ui`, `business-edit-ui`, `business-dashboard-ui`, `business-ui`, queue services, more). Page update itself every hour. You do nothing. You only look.

---

## Two tabs. Two questions.

### 🟢 Pre-release tab — "what next?"

**https://mruff-aeq.github.io/bcgov-release-tracker/#pre**

For dev. Show every PR merged but NOT yet pushed to TEST.

- Green pill say **how many PRs waiting** per repo.
- Green line in log show **last TEST push** — the starting line.
- Faded section mean **nothing waiting there**. Eyes skip. Save time.

### 🟢 Post-release tab — "what in TEST now?"

**https://mruff-aeq.github.io/bcgov-release-tracker/#post**

For QA. Show every PR that went into TEST **this release cycle**, with date right in title.

- Green pill mean **repo part of newest TEST push**.
- Faded section mean **old push, not this cycle**. Still there, just quiet.
- Bottom of page: current **versions** and **CD workflow links**, same green pills so easy match.

---

## Who use?

- **Dev before release day**: open pre tab, see what riding next train to TEST.
- **QA after push**: open post tab, see exactly what to test and which versions live.
- **Anyone curious**: click link. Look at green things. Green mean now.

That all. Cave simple. 🦴
